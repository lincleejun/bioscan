# Third-party skills: mattpocock/skills

The 25 skills in this directory are copied unmodified from
https://github.com/mattpocock/skills at commit c55ee46 (plugin version 1.2.3): exactly the set the
`mattpocock-skills` Claude Code plugin ships (`.claude-plugin/plugin.json`). The upstream
`in-progress/`, `misc/` and `deprecated/` buckets are not included, same as the plugin.

Installed as project files (the "tinkerers" route in the upstream README) so they are versioned
with this repo and can be edited. To update: re-copy from a newer upstream commit and note it here.
Run `/setup-matt-pocock-skills` once to configure issue tracker, triage labels and docs location
(only some skills need it; `/improve-codebase-architecture` does not).

Note: `code-review` has the same name as a Claude Code built-in skill.
